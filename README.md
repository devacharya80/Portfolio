# Devacharya Portfolio

Recruiter-focused personal portfolio and private engineering workspace.

## Monorepo
- apps/web — public React + TypeScript + Tailwind portfolio and private workspace UI
- apps/api — Node.js + Express + TypeScript API
- packages/config — shared configuration
- packages/types — shared TypeScript contracts
- services/ai — reserved boundary for future Python/FastAPI RAG and AI services

## Principles
- Recruiter-first presentation
- Separation of concerns
- Public portfolio isolated from private workspace data
- PostgreSQL + Prisma
- Lightweight Motion animations
- Responsive and accessible by default
- Future AI/RAG integration without restructuring the current system

This repository is intentionally scaffolded with placeholders for information that has not been verified yet.
